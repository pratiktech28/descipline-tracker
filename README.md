<h1>📌 Executive Overview</h1>
<p>
  <b>Daily Discipline</b> is structured around a human-first approach to habit tracking: 
  <i>"A little structure. A lot of room to grow."</i> Instead of overwhelming task overload, it provides a clean space to align daily moments chronologically, run focus sprints, track consistency metrics, and record daily reflections.
</p>

<hr />

<h1>🎨 Architecture & Key Features</h1>

<h2>1. High-Impact Hero Dashboard</h2>
<p>Displays dynamic headline messaging, date navigation controls, and live status pills along with a clean cream-toned glassmorphism dark UI theme.</p>

<h2>2. Real-Time Progress & Analytics</h2>
<ul>
  <li><b>Your Day in Motion:</b> Calculates real-time completion percentage based on checked daily habits.</li>
  <li><b>Little Wins Tally:</b> Displays exact counts of finished daily routines.</li>
  <li><b>Steady Days (Streak System):</b> Increments daily streak counter automatically upon achieving target daily goals.</li>
</ul>

<h2>3. Integrated Focus & Reflection Tools</h2>
<ul>
  <li><b>Focus Session Timer:</b> Built-in 50-minute Pomodoro timer for deep work sessions with Start and Reset controls.</li>
  <li><b>Weekly Rhythm Matrix:</b> Visual calendar component tracking daily activity across Monday to Sunday.</li>
  <li><b>A Note to Yourself:</b> Auto-saved digital reflection box persistent across browser reloads.</li>
</ul>

<h1>🛠️ Local Setup Instructions</h1>

<h3>1. Clone Repository</h3>
<pre><code>git clone https://github.com/pratiktechh/daily-discipline.git
cd daily-discipline</code></pre>

<h3>2. Install Dependencies</h3>
<pre><code>pnpm install
# or
npm install</code></pre>

<h3>3. Start Development Server</h3>
<pre><code>pnpm dev
# or
npm run dev</code></pre>

<p>Open <code>http://localhost:5173</code> in your web browser.</p>
